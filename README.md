# 🌐 Portfólio Pessoal - Diogo Mateus

Este repositório contém o código-fonte do meu portfólio pessoal, um website responsivo do tipo *Single Page Application* (SPA) desenvolvido para apresentar o meu percurso, competências técnicas e projetos na área de programação e cibersegurança.

---

## 🚀 Demonstração das Funcionalidades

- **Navegação Sticky:** Menu superior fixo para fácil acesso a todas as secções da página.
- **Apresentação Hero:** Secção inicial de destaque com introdução e botões de navegação rápida (*Call to Action*).
- **Sobre Mim:** Apresentação breve sobre os meus objetivos e interesses.
- **Competências e Tecnologias:** Cartões interativos a destacar os conhecimentos em HTML5, Bootstrap, Python, Flask, SQL e Cibersegurança.
- **Galeria de Projetos:** Exibição dos projetos desenvolvidos (*Gestor de Tarefas*, *Página de Portfólio*, *Laboratório de Segurança*) com etiquetas (*badges*) e descrições.
- **Formulário de Contacto:** Formulário responsivo com validações nativas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da página.
- **Bootstrap 5 (v5.3.8):** Sistema de grelha responsiva e componentes de UI.
- **Bootstrap Icons (v1.13.1):** Ícones vetoriais.
